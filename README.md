# Farfalle al Salmone 🍝

Интерактивный пошаговый кулинарный гид для приготовления фарфалле со стейком лосося в сливочном соусе 33% с белым вином и чиабаттой.

## Возможности
- 🛒 **Список в супермаркет**: строчный чеклист ингредиентов с граммами и рекомендациями брендов.
- 🔄 **Сквозная синхронизация телефон ↔ ПК**: отмечайте покупки в магазине на смартфоне, и всё мгновенно синхронизируется с домашним компьютером в реальном времени.
- ⚖️ **Пересчет порций**: автоматический перерасчет всех граммовок на лету (1–8 порций).
- ⏱ **Живые таймеры на 2 конфорки**: точные таймеры на `Date.now()` со звуковыми сигналами.
- 👨‍🍳 **Режим «Шеф на кухне»**: полноэкранный режим с крупными цифрами и предотвращением затухания экрана (Screen Wake Lock API).
- 📱 **100% автономность**: работает полностью в одном файле `index.html`.
